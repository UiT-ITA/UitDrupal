# UiB Drupal Site Base

This directory contain a base configutration for generic websites built with
Drupal 10+ in a UiB adm-it-pub context.

Here we set environment variables for the Drupal cronjob and php-fpm common
across all UiB adm-it-pub Drupal projects.

These variables are used by the settings files found in our
[Drupal Scaffolding package](https://git.app.uib.no/itpublic/composer-packages/drupal-scaffold).
